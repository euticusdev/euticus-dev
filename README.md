## ⚙️ Installation and Setup

Follow these steps to run Euticus Dev locally.

### 1. Clone the repository

```bash
git clone https://github.com/euticusdev/euticus-dev.git
cd euticus-dev
```

### 2. Create and activate a virtual environment

On Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

Install Django and the required Python packages in your activated environment.

### 4. Configure environment variables

Create a `.env` file in the project root and set your own Django secret key using the variable `DJANGO_SECRET_KEY`.

Never publish your `.env` file or share your secret key.

### 5. Run the development server

```bash
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser.

## 🚀 Usage

After completing the installation steps and starting the Django development server, open the following address in your web browser:

http://127.0.0.1:8000/

You should see the Euticus Dev homepage.

The project is under active development, and more functionality will be introduced over time.
